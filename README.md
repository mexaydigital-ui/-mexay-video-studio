# MexAy Video Studio

120 saniyelik Türkçe MexAy Digital reklamı. Remotion ile 1080x1920, 30 FPS, 9:16 MP4 oluşturur.

## Yerel kullanım

```bash
npm install
npm run preview
npm run render
```

## GitHub Actions

Actions > Render MexAy Video > Run workflow. Başarılı çalışmanın Artifacts bölümünden `mexay-digital-tr-video` dosyasını indirin.

Ücretsiz standart GitHub Actions çalıştırıcısı kullanır. Ücretli API, harici servis veya ödeme anahtarı gerektirmez. Seslendirme ve müzik henüz ekli değildir. Bu ilk sürüm animasyonlu ve sessizdir.
